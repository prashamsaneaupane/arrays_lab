
# Class Exercise/Lab -  Student Grade Analyzer

Create a program that analyzes student test scores stored in an array.

Given an array of student grades, calculate and display

Calculate and Display
-- Total Score
-- Average Score
-- Highest Score
-- Lowest Score

```
int[] scores = {
    85, 92, 78, 95, 88,
    76, 91, 84, 89, 93
};
```

Expected Output:
```
Item	Value
Total	871
Average	87.1
Highest	95
Lowest	76
```
